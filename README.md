# Hacktoberfest 2026 submissions

Write-ups for the [Hacktoberfest Open-Source AI Challenge](https://hacktoberfest.com), 2026.

The challenge is a sequence of weekly **DEV Challenges**: each has a secret theme, and the
entry is a **DEV post** on [dev.to](https://dev.to) tagged `#devchallenge` `#hf26challenge`.
There is no pull-request requirement in 2026 — the post is the submission.

This repository is a record only. The code for each entry lives in its own repository, and
the post itself is published on DEV.to.

## Weeks

1. **Oct 5–11 — Touch Grass.** `chidambaram-birdnudge`: offline bird-call identification
   for Chidambaram, Tamil Nadu. BirdNET V3.0 through ONNX Runtime in pure Node, with every
   prediction filtered against an iNaturalist-derived species pack built from local
   observations. The motivating measurement: the same model and the same code score **1/20**
   in-pack on a New York soundscape and **23/33** on recordings made here. Nineteen of the
   twenty species BirdNET proposed for the New York audio do not exist within 30 km of
   Chidambaram.
